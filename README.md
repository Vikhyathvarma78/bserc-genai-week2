# BSERC GenAI Internship - Week 2 Submissions
**Student Repository for Week 2 Projects**

This repository contains the source code for all 8 required projects from the Section A, B, C, and D milestone.
All projects are built natively using standard web technologies (HTML, CSS, JS) and operate 100% offline or locally in the browser.

## Repository Contents
* `01_form_photo_fixer`: Client-side image crop & compression tool.
* `02_scribbly_notes`: Generates handwritten notes from text using HTML5 Canvas.
* `03_bill_book`: Offline progressive web app for shop billing with UPI QR generation.
* `04_auto_rally`: HTML5 Canvas 2D racing game.
* `05_job_clipper`: Chrome Manifest V3 extension to clip job details into local storage.
* `06_style_spy`: Chrome Manifest V3 extension to scrape DOM colors/fonts.
* `07_viva_skill`: The prompt design for an AI examiner agent.
* `08_page_redesign`: HTML/CSS visual refactoring of a college fest landing page.
* `prompts.md`: The complete audit log of prompts used during the week.
* `report.md`: The final requirement report detailing features and criteria checks.
