# Prompt Audit Log

### Project 1: Form Photo Fixer
- **Prompt:** "Create a single-page HTML application using vanilla JS and Canvas that allows users to upload a photo, crop it, and iteratively compress it using standard JPEG quality adjustment until it hits a target KB limit (e.g. 50KB). Make sure it looks professional and runs entirely offline."

### Project 2: Scribbly Notes
- **Prompt:** "Build a web tool that takes text from a textarea and draws it onto an HTML canvas that looks like lined notebook paper. Use a handwritten font and introduce a small random offset (jitter) to the text baseline and rotation so it feels human, not machine generated."

### Project 3: Bill Book
- **Prompt:** "Code a mobile-first HTML/JS app for a shopkeeper. They need to enter an item name, price, and quantity. It should calculate the total dynamically and generate a UPI payment QR code automatically using the qrcode.js library. Make the UI clean."

### Project 4: Auto Rally
- **Prompt:** "Write a simple 2D car dodging game using HTML5 Canvas. The player controls a yellow auto-rickshaw using arrow keys or on-screen touch buttons. Random red squares act as obstacles and gold circles act as coins. Add a simple score and a 3-lap loop."

### Project 5: Job Clipper
- **Prompt:** "I need a Chrome Extension (Manifest V3) that helps me save job applications. Provide the manifest.json and a popup.html with inline JS. It should have a small form to save Role, Company, and Deadline to chrome.storage.local, display them in a list, and have an Export CSV button."

### Project 6: Style Spy
- **Prompt:** "Create another Manifest V3 extension. When clicked, it should execute a script on the active tab that reads the `window.getComputedStyle` of the top 100 elements. Extract unique font-families and colors, then display them in the popup formatted as CSS variables."

### Project 7: Viva Skill
- **Prompt:** "Write a system prompt for an AI agent to act as a strict Viva examiner. It needs rules to ensure it only asks one question at a time, waits for the user answer, scores it out of 5, and then proceeds. Finally, it gives a total scorecard out of 25."

### Project 8: Page Redesign
- **Prompt:** "Take this basic HTML template about a college fest. Keep all text exactly the same, but rewrite the CSS to make it look like a modern, dark-mode, high-end SaaS landing page using CSS grid, smooth hover effects, and linear gradients."
